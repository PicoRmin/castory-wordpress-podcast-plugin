# Trending Audio Episodes — Premium Podcast Streaming Platform

Create a **pixel-perfect, production-quality dark-mode podcast streaming platform page** called **"Trending Audio Episodes"**.

The page should represent a modern premium podcast ecosystem inspired by Spotify, Apple Podcasts, Linear, Arc Browser, YouTube Music, and Netflix.

Use only:

* HTML5
* CSS3
* Vanilla JavaScript
* No frameworks
* No Bootstrap
* No Tailwind
* Fully responsive
* Production-ready code

## Responsive Design

### Tablet (≤1024px)

* Right sidebar moves below content
* Hero becomes stacked
* Filters wrap naturally
* Sidebar width reduced

### Mobile (≤768px)

* Sidebar becomes off-canvas drawer
* Hamburger menu appears
* Hero stacks vertically
* Headphones image scales down
* Episode table transforms into cards
* Right sidebar moves below content
* Pagination becomes horizontally scrollable

No horizontal overflow should occur on mobile devices.
