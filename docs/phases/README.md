## قالب استاندارد (برای فازهای بعد)

هر گزارش فاز باید شامل این بخش‌ها باشد:

1. **خلاصه** — هدف، وضعیت، تاریخ
2. **فایل‌های ایجاد/تغییر یافته** — جدول path + action
3. **ترتیب Load** — CSS و JS به ترتیب
4. **User Flow** — مسیر کاربر در UI
5. **Workflow توسعه** — گردش کار dev/فاز بعد
6. **API کلیدها** — JS/CSS/Data
7. **Preview & Files** — URL باز کردن + entry points
8. **وضعیت صفحات** — جدول completeness
9. **Known Issues** — باگ‌ها و بدهی فنی
10. **Handoff to Next Phase** — کارهای فاز بعد
